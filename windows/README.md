# Windows launcher

Run `calligraphy-screensaver.bat` (or the PowerShell script).

- Prefers Microsoft Edge, Google Chrome, or Brave in fullscreen `--app` mode with `?wake=1`.
- If those browsers are missing, [mpv](https://mpv.io/) on PATH loops `videos/playlist.m3u`.
- Otherwise the Canvas `index.html` opens in the default browser. Press `F` for fullscreen.
- Keys: Space pause; arrows change boards; `T`/`I`/`V` toggle F.Cu / inner copper / vias; `[` `]` speed; Esc/Q exit.
- Optional: Windows Settings → Personalization → Lock screen / Screen saver can point at the `videos` folder.
