# macOS launcher

Double-click `calligraphy-screensaver.command`.

- Prefers Google Chrome, Brave, or Microsoft Edge in fullscreen `--app` mode with `?wake=1`.
- Next: `mpv` looping `videos/playlist.m3u` (`brew install mpv`).
- Fallback: Safari opens `index.html`. Use Control-Command-F for fullscreen.
- Keys: Space pause; arrows change boards; `T`/`I`/`V` toggle F.Cu / inner copper / vias; `[` `]` speed; Esc/Q exit.
- Optional: System Settings → Screen Saver → Other → pick a folder of the MP4 files in `videos/`.
